# Документация разработчика

Этот раздел предназначен для сопровождения и развития PrintNum. Его задача — объяснить устройство проекта так, чтобы изменения можно было безопасно вносить и проверять без необходимости изучать весь код заново.

## Темы

- **Архитектура проекта** — основные компоненты и связи между ними.
- **Backend** — запуск, API, фоновые задачи, взаимодействие с принтером и ресурсами.
- **Браузерное расширение** — структура, режимы работы, связь с приложением и сборка.
- **Frontend** — организация интерфейса и управление состоянием.
- **Сборка и релиз** — локальная разработка, тестирование, упаковка и публикация обновлений.

## Правила

- Документировать фактическое поведение, подтверждённое кодом.
- Указывать точные команды запуска и сборки.
- Не дублировать большие фрагменты исходного кода: вместо этого ссылаться на файлы и описывать назначение.
- Обновлять соответствующие страницы в том же Pull Request, который меняет описываемое поведение.
- Отдельно отмечать различия между production- и dev-режимами.
