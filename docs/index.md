# Документация PrintNum

Добро пожаловать в документацию PrintNum. Здесь будут собраны инструкции по работе с приложением и браузерным расширением, а также технические сведения для разработки и сопровождения проекта.

## Разделы

- **[Пользователям](user/index.md)** — установка, настройка, печать, создание этикеток, работа с расширением и решение проблем.
- **[Разработчикам](developer/index.md)** — архитектура приложения, backend, браузерное расширение, сборка и обслуживание.

## О проекте

PrintNum — приложение для Windows, которое помогает автоматизировать печать номеров ячеек Ozon и создавать собственные этикетки.

Документация ведётся в Markdown непосредственно в репозитории. Изменения в ней проходят обычное код-ревью через Pull Request.

> Описания пользовательских функций должны соответствовать production-режиму приложения и расширения. Возможности, доступные только в dev-режиме, необходимо явно помечать как разработческие.
