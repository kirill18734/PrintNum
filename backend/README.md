# PrintNum Backend

Локальный Flask backend для приложения PrintNum. Поддерживает автоматическую и ручную печать, управление ресурсами и интеграцию с Tauri.

## Разработка

В каталоге backend создайте виртуальное окружение, установите зависимости из requirements.txt и запустите python backend.py.

Сервер слушает только loopback-интерфейс 127.0.0.1:5000. Для автономного режима без автоматического завершения по простою используйте python backend.py --standalone.

## API

- GET / — проверка доступности.
- GET /data-app — состояние принтера, список принтеров, фоны, метаданные шрифтов и последние задания.
- GET /fonts/{id} — Base64 конкретного шрифта. Идентификатор основан на SHA-256 содержимого.
- GET /status-printer — принудительная проверка принтера.
- GET /listPrinters — список установленных принтеров.
- POST /print-label — ручная печать этикетки.
- POST /print-number и POST /ozon-shelf — автоматическая печать; оба маршрута сохранены для браузерного расширения.
- POST /shutdown — штатная остановка, доступна только локальному клиенту с заголовком X-PrintNum-Shutdown: local-client.

Шрифты передаются отдельно, поэтому частый опрос /data-app не отправляет повторно большие Base64-строки. Frontend кеширует бинарные данные по content-hash идентификатору.

## Ресурсы

Backend загружает шрифты из %LOCALAPPDATA%\\PrintNum\\resources\\fonts и изображения из %LOCALAPPDATA%\\PrintNum\\resources\\images. Поддерживаются TTF и OTF. Для шрифтов возвращаются семейство, CSS-вес, normal/italic и формат из метаданных файла.

Настройки читаются из %APPDATA%\\PrintNum\\config.json; если файла там нет, используется локальный config.json.
