# Amvera backend: сервер обновлений

Этот каталог содержит минимальный Python-сервис, который используется как сервер обновлений для публикации файлов и JSON-метаданных через Amvera.

Amvera — облачная платформа для размещения и запуска приложений без лишней настройки инфраструктуры. Официальный сайт: [amvera.ru](https://amvera.ru).

Сервис написан на Flask и запускается из файла [main.py](main.py). Он использует каталог `/data` как хранилище с примонтированным постоянным томом и отдает его содержимое по HTTP.

## Что делает сервис

- На `GET /` отвечает строкой `Hello World`.
- На `GET /latest.json` читает файл `/data/latest.json` и возвращает его как JSON.
- На `GET /<path>` отдает любой файл или вложенный путь из `/data` как скачиваемый файл.

Пример: если в `/data` лежит папка версии приложения, например `v1.0.0`, то по адресу `v1.0.0/PrintNum_1.0.0_x64-setup.exe` можно получить файл `PrintNum_1.0.0_x64-setup.exe` из этой версии.

## Структура

- [main.py](main.py) — основной Flask-приложение и маршруты.
- [requirements.txt](requirements.txt) — зависимости Python.
- [amvera.yml](amvera.yml) — конфигурация сборки и запуска для Amvera.

## Локальный запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустите приложение:

   ```bash
   python main.py
   ```

3. Проверьте доступные маршруты:
   - `http://127.0.0.1:5000/`
   - `http://127.0.0.1:5000/latest.json`

## Деплой в Amvera

Конфигурация в [amvera.yml](amvera.yml) уже настроена на:

- Python 3.11
- установку зависимостей из `requirements.txt`
- запуск `main.py`
- порт контейнера `5000`
- сервисный порт `80`
- постоянное хранилище в `/data`

При деплое важно, чтобы файл `latest.json` и другие публикуемые артефакты находились именно в `/data`.

## Примечания

- В приложении отключено экранирование кириллицы в JSON-ответах.
- Для отдачи файлов используется `send_from_directory`, поэтому вложенные пути поддерживаются.
