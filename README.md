# Печать ячеек Ozon

Windows-приложение для автоматической печати номеров.

![alt text](public/icon.ico)

## Стек технологий

|            Client             |              Server               |      Desktop-оболочка       |
| :---------------------------: | :-------------------------------: | :-------------------------: |
| [React](https://reactjs.org/) | [Python](https://www.python.org/) | [Tauri](https://tauri.app/) |

## 🚀 Быстрый старт

1. Скачать MSI-установщик: найти в разделе `Releases` файл `printnum_0.1.0_x64_en-US.zip`
1. Установить и запустить программу `PrintNum`.
1. Запустить приложение по кнопке "Запустить"
1. Необходимо перейти в настройки <img src="public/settings.ico" width="30em"> , указать:
   - принтер
   - размер этикетки
1. Открыть страницу в бразуере (Yandex, Chrome):<br>
   `chrome://extensions/`
1. Включить «Режим разработчика» (правый верхний угол).
1. Нажать **«Загрузить распакованное расширение»**.
1. Указать путь к папке:
   %LOCALAPPDATA%\PrintNum\extension
   (полный путь можно найти следующим образом: Win + R → вставить %LOCALAPPDATA%\PrintNum\ → Shift + ПКМ по папке extension → «Копировать как путь»).
1. Вставить путь до папки и нажать "Выбор папки"
1. Обновить вкладки браузера (если они были открыты до установки расширения).
1. Запустить программу

## Возможности

[(Вернуться к началу)](#печать-ячеек-ozon)

### Возможности приложения

- Переключение светлой/тёмной темы
- Выбор принтера из списка доступных на ПК
- Выбор размера этикетки
- Выбор формата печати текста
- Автоматические обновления

### Возможности расширения

- Скрытие элементов: данная функция отключена по умолчанию. Чтобы включить её, перейдите в папку расширения по пути: `%LOCALAPPDATA%\PrintNum\extension`, откройте файл `index.js` и измените значение:
`const ENABLE_FEATURE = false` → `const ENABLE_FEATURE = true`. После этого в левом нижнем углу появится кнопка 🎁:

```
🎁
 |
Скрыть
 ├── Меню — позволяет скрывать разделы в главном меню
 ├── Возвраты — позволяет скрывать возвраты (работает только в разделе
 │   «Отправка → Отправка перевозок → Прямой/Возвратный поток»)
 └── Уведомления — позволяет скрывать уведомления в указанных разделах меню

```

- Отправка номеров ячеек для распечатки
- Возможность дополнительно ускорить работу с помощью QR-кодов (актуальный список — в файле qrcodeOzon.docx):

1. Автозакрытие карточек для выдачи:

   1.1. QR-коды «Выдать всё (без пакета, пакет M, пакет L)» —
   работают только в разделе «Выдача заказов» и только с предоплаченными (оплаченными) заказами.

   1.2. QR-коды «Выдать заказ (без пакета, пакет M, пакет L)» —
   работают только в разделе «Выдача заказов» → «Открытая карточка заказа» и только с предоплаченными (оплаченными) заказами.

   1.3. QR-коды «Оплатить заказ (без пакета, пакет M, пакет L)» —
   работают только в разделе «Выдача заказов» → «Открытая карточка заказа» и только с неоплаченными заказами.

2. Оформление возврата:

   2.1. QR-код «Изменил решение о покупке / Товар не подошёл» —
   - необходимо отсканировать товар, который вернул клиент;
   - в течение 3 секунд нужно отсканировать данный QR-код.

3. Ускорение оформления возвратов — как это работает:
   - Перейдите в раздел оформления возвратов:
     «Отправка → Отправка перевозок → Прямой/Возвратный поток».

   - Выберите любой возврат, который требуется дополнительно упаковать.

   - Отсканируйте товар. В появившемся окне выбора упаковки автоматически будет выбран пункт «Упаковка не требуется».

   - После этого можно взять новый ШК и отсканировать его — кнопка «Завершить» нажмётся автоматически.

   - Затем нужно повторно отсканировать товар с новым ШК — он добавится в перевозку.

## Разработка

[(Вернуться к началу)](#печать-ячеек-ozon)

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/kirill18734/PrintNum.git
   cd PrintNum/backend/
   ```

1. Установить Python 3.10+ с [python.org](https://www.python.org/) (с опцией _Add Python to PATH_).

1. Создать виртуальное окружение и активировать его:

   ```bash
   python -m venv .venv
   .venv\\Scripts\\activate
   ```

1. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

1. Запустить backend на Python:

   ```bash
   python backend.py
   ```

   или собрать в `.exe` через **auto-py-to-exe**:
   - Script Location: `backend.py`.
   - Icon: `icon.ico`
   - Additional Files: Add Files - `data.py`, `print_text.py`, `utils.py`.

   После компиляции долждна создаться папка output со следующей структурой:

   ```
   output/
   └── backend/
       ├── _internal/
       └── backend.exe
   ```

1. Установить зависимости для Tauri: [tauri.app/start/prerequisites](https://tauri.app/start/prerequisites/)

1. Установить зависимости для всего проекта:

   ```bash
   npm install
   ```

1. Запустить Tauri в режиме разработки:

   ```bash
   npm run tauri dev
   ```

## Структура проекта

- `backend/` — серверная логика (Python).
- `src/` — интерфейс (REACT).
- `src-tauri/` — конфигурация и сборка Tauri.
