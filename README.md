# PrintNum

Это ветка `core` репозитория PrintNum, содержащая исходное ядро приложения для продвинутых пользователей. Она предполагает ручную установку и настройку: здесь нет графического интерфейса для установки или управления сервисом печати.

Отдельного интерфейса для настройки backend здесь нет: параметры сервиса задаются вручную в `backend/config.json`. Popup расширения показывает состояние сервиса и содержит ссылку на загрузку приложения для Windows. Для готовой и более удобной версии с интерфейсом перейдите в ветку [main](https://github.com) этого же репозитория.

Ядро печатает номера ячеек из личного кабинета пункта выдачи Ozon (`turbo-pvz.ozon.ru`) на локальный термопринтер. В репозитории две части (подробные инструкции по работе и настройке находятся внутри каждой из папок):

- `backend/` — локальный Flask-сервис, который форматирует и отправляет текст на Windows-принтер;
- `extension/` — Chrome-расширение для печати рекомендуемых ячеек, новых ячеек Ozon Полки и дополнительных автоматизаций интерфейса Ozon.
