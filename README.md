# <img src="./public/favicon.ico" width="50em">PrintNum — Печать ячеек (Ozon)

## 🚀 Быстрый старт

1. **Скачайте MSI-установщик**: Перейдите в раздел [Releases](https://github.com/kirill18734/PrintNum/releases) и скачайте `PrintNum_2.0.0_x64-setup.exe`.
2. **Установите приложение**: Запустите MSI и следуйте инструкциям инсталлятора.
3. **Запустите PrintNum**: Откройте приложение из меню "Пуск" или ярлыка на рабочем столе.
4. **Настройте параметры**: Перейдите в "Настройки" <img src="public/settings.png" width="30em"> и укажите:
   - **Принтер**: Выберите из списка доступных на ПК.
   - **Размер этикетки**: Укажите ширину и высоту в мм.
   - **Стиль этикетки**: Параметры форматирования и рокировки текста.
5. **Установите расширение**:
   - Откройте `chrome://extensions/` в браузере (Yandex, Chrome).
   - Включите "Режим разработчика".
   - Найдите папку, в которой находится основной `.exe` файл программы, и скопируйте путь к этой папке.
     (см. [Как открыть расположение исполняемого EXE файла программы в Windows](https://remontka.pro/open-exe-file-location-windows)).
   - Внутри этой же директории находится папка `extension` — именно её нужно выбрать для установки.
   - Нажмите "Загрузить распакованное расширение"
   - Выберите папку `extension`.

6. **Обновите вкладки**: Перезагрузите открытые вкладки Ozon.
7. **Готово**: Расширение активно на turbo-pvz.ozon.ru.

## Архитектура

Проект использует модульную архитектуру для разделения ответственности между 4 независимыми компонентами:

### 🎨 **Frontend (React + React-Router)**

- Управляет пользовательским интерфейсом, темами оформления и конфигурацией приложения
- Коммуницирует с backend через HTTP запросы (`api.ts`)
- Реализует 13+ встроенных тем и поддержку темного/светлого режима
- Управляет состоянием настроек (принтер, размеры, стили)

### 🔧 **Backend (Flask + Python)**

- REST API сервер для обработки запросов на печать
- Управляет конфигурацией (сохранение/загрузка JSON)
- Взаимодействует с Windows API через `pywin32` для работы с принтерами
- Автоматически завершается через 15 сек неактивности (watchdog)

### 📱 **Desktop (Tauri + Rust)**

- Обеспечивает нативную оболочку приложения для Windows
- Управляет автообновлениями (скачивание и установка новых версий)
- Запускает Python backend процесс при старте приложения
- Предоставляет доступ к Windows API через плагины (диалоги, логирование, работа с процессами)

### 🌐 **Браузерное расширение (JavaScript + Manifest V3)**

- Инжектирует скрипты в страницы Ozon (turbo-pvz.ozon.ru)
- Автоматически захватывает номера ячеек и отправляет их на backend для печати
- Предоставляет автоматизацию процессов (выдача заказов, оформление возвратов, приемка)

```
Пользователь                    Ozon сайт
   ↓                               ↓
 Desktop UI ────────────→ Браузерное расширение
   ↓                               ↓
 React-Router                 Content Scripts
   ↓                               ↓
[API Client] ←──────────────[fetch request]
   ↓                               ↓
 Flask Backend
   ↓
[Windows API - Принтер]
   ↓
  📄 Печать этикетки
```

## Требования

[(Вернуться к началу)](#printnum--печать-ячеек-ozon)

- **Браузер**: Chrome, Yandex Browser или другие Chromium-совместимые браузеры (поддержка Manifest V3).

### Возможности приложения

- 🖨️ **Выбор принтера**: Автоматическое определение всех доступных на ПК принтеров.
- 📏 **Параметры этикетки**: Настройка ширины, высоты и отступов (в мм или пиксели).
- 🔤 **Форматирование текста**: Рокировка (swap) текстов, включение/отключение ID, гибридный режим.
- 🌙 **Темы оформления**: 13+ встроенных тем (Claude, Cyberpunk, Terminal, Zen и др.) + светлый/темный режим.
- 🎨 **Кастомизация интерфейса**: Выбор стиля оформления этикетки и целевого оформления.
- 🔄 **Автоматические обновления**: Встроенный updater на базе Tauri для скачивания новых версий.
- 💾 **Сохранение конфигурации**: Все параметры сохраняются и восстанавливаются при запуске.

### Возможности расширения

- **Скрытие элементов** (отключено по умолчанию): Включите в `extension/index.js` (`ENABLE_FEATURE = true`). Добавляет кнопку 🎁 в левом нижнем углу для скрытия меню, возвратов и уведомлений.
- **Печать номеров ячеек**: Автоматическая отправка номеров на печать.
- **QR-коды для ускорения** (см. `qrcodeOzon.docx`):
  - Автозакрытие карточек выдачи (для предоплаченных/неоплаченных заказов).
  - Оформление возвратов.
  - Ускорение упаковки в разделе "Отправка перевозок".

## Как использовать расширение правильно

Расширение интегрируется с сайтом Ozon (turbo-pvz.ozon.ru) и предоставляет автоматизацию для ускорения работы. Убедитесь, что desktop-приложение запущено и сервер доступен.

### Скрытие элементов интерфейса

Функция отключена по умолчанию для безопасности. Чтобы включить:

1. Перейдите в папку, в которой находится основной `.exe` файл программы.
   (см. [Как открыть расположение исполняемого EXE файла программы в Windows](https://remontka.pro/open-exe-file-location-windows)).
2. Внутри этой же директории находится папка `extension`
3. Откройте `index.js`.
4. Измените и сохраните `const ENABLE_FEATURE = false;` на `const ENABLE_FEATURE = true;`
5. Перезагрузите браузер.

После включения в левом нижнем углу появится кнопка 🎁. Нажмите её, чтобы открыть меню скрытия:

- **Меню**: Скрывает разделы главного меню Ozon. Выберите пункты для скрытия — они исчезнут со страницы и сохранятся в localStorage браузера.
- **Уведомления**: Скрывает уведомления в указанных разделах.
- **Возвраты**: Скрывает возвраты (работает только в разделе "Отправка → Отправка перевозок → Прямой/Возвратный поток").

### Автоматическая печать номеров ячеек

При приемке товаров на странице `receiving-v2/main` расширение автоматически отслеживает новые номера ячеек и отправляет их на сервер печати (`http://127.0.0.1:5000/print-number`). Номера печатаются согласно настройкам приложения.

### Использование QR-кодов для автоматизации

Сканируйте QR-коды из `qrcodeOzon.docx` для автоматического выполнения действий на сайте Ozon. Каждый код соответствует последовательности кликов (actions) в коде расширения.

#### Автозакрытие карточек для выдачи:

- **Выдать заказ (без пакета/M/L)**: Работает в разделе "Выдача заказов → Открытая карточка заказа" для предоплаченных заказов. Выполняет: Продолжить → [Выбор пакета] → Выдать → На главную.
- **Выдать всё (без пакета/M/L)**: Работает в разделе "Выдача заказов" для предоплаченных заказов. Повторяет для всех готовых заказов: К выдаче → Продолжить → [Выбор пакета] → Выдать → На главную.
- **Оплатить заказ (без пакета/M/L)**: Работает в разделе "Выдача заказов → Открытая карточка заказа" для неоплаченных заказов. Выполняет: Продолжить → [Выбор пакета] → Провести оплату → На главную.

#### Оформление возврата:

- **Изменил решение о покупке / Товар не подошёл**: Отсканируйте товар, затем в течение 3 секунд отсканируйте QR-код для выбора причины возврата.

#### Ускорение оформления возвратов:

В разделе "Отправка → Отправка перевозок → Прямой/Возвратный поток":

1. Выберите возврат для упаковки.
2. Отсканируйте товар — автоматически выберется "Упаковка не требуется".
3. Возьмите новый ШК, отсканируйте — кнопка "Завершить" нажмётся автоматически.
4. Повторно отсканируйте товар с новым ШК — он добавится в перевозку.

**Примечание**: Автоматизация работает только на указанных страницах и требует точного следования инструкциям, чтобы избежать ошибок.

## API документация

Backend предоставляет REST API на Flask на порту `5000`. Все эндпоинты поддерживают CORS и работают с JSON.

| Метод    | Эндпоинт        | Описание                           | Ответ                                      |
| -------- | --------------- | ---------------------------------- | ------------------------------------------ |
| **GET**  | `/`             | Ping/проверка доступности          | `"Hello, World!"`                          |
| **POST** | `/get-config`   | Получить конфиг и список принтеров | `{"config": {...}, "printers": [...]}`     |
| **POST** | `/statePrinter` | Проверка статуса принтера          | `{"state": "OK"}` или `{"state": "ERROR"}` |
| **POST** | `/set_config`   | Сохранить настройки                | `{"update_config": "OK"}`                  |
| **POST** | `/print-number` | Печать номера ячейки               | `{"status": "printed"}`                    |

**Базовый URL**: `http://127.0.0.1:5000`  
**Автозавершение**: Сервер автоматически завершается через 15 секунд неактивности (watchdog).

## Разработка

[(Вернуться к началу)](#printnum--печать-ячеек-ozon)

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/kirill18734/PrintNum.git
   cd PrintNum
   ```

2. **Настройте backend**:
   - Установите Python 3.10+ с [python.org](https://www.python.org/) (добавьте в PATH).
   - Перейдите в папку `backend`:
     ```bash
     cd backend
     ```
   - Создайте виртуальное окружение:
     ```bash
     python -m venv .venv
     .venv\Scripts\activate  # Windows
     ```
   - Установите зависимости:
     ```bash
     pip install -r requirements.txt
     ```
   - Запустите сервер:
     ```bash
     python backend.py
     ```
   - Сервер запустится на `http://localhost:5000`

3. **Настройте frontend** (в корне проекта):
   - Убедитесь, что Node.js 18+ установлен.
   - Установите зависимости:
     ```bash
     npm install
     ```
   - Запустите dev-сервер Vite:
     ```bash
     npm run dev
     ```
   - Frontend откроется на `http://localhost:5173`

4. **Запустите Tauri** (нативное приложение):
   - Установите prerequisites для вашей ОС: [tauri.app/start/prerequisites](https://tauri.app/start/prerequisites/)
   - В корне проекта запустите:
     ```bash
     npm run tauri dev
     ```
   - Откроется окно приложения с HMR (hot-reload)

5. **Тестируйте расширение**:
   - Откройте `chrome://extensions/` в браузере.
   - Включите "Режим разработчика".
   - Нажмите "Загрузить распакованное расширение".
   - Выберите папку `extension/` из проекта.
   - Перезагрузите вкладки Ozon (turbo-pvz.ozon.ru).

## Сборка и установка

[(Вернуться к началу)](#printnum--печать-ячеек-ozon)

- **Backend в EXE**: Используйте [auto-py-to-exe](https://github.com/brentyi/auto-py-to-exe):
  1. Откройте auto-py-to-exe в папке `backend/`
  2. Выберите `backend.py` как основной скрипт
  3. Добавьте как "Additional files": `data.py`, `print_text.py`, `utils.py`
  4. Установите опции: One File, Console Window Disabled
  5. Build → готовый EXE будет в `backend/output/backend/`
- **Полная сборка приложения**:

  ```bash
  npm run build       # Сборка frontend
  npm run tauri build # Сборка Tauri (создаст MSI)
  ```

  MSI-инсталлятор будет в `src-tauri/target/release/bundle/nsis/`

- **Установка через MSI**: Запустите `.msi` файл. Приложение установится с расширением и backend'ом.
