# 🌐 PrintNum Extension

Браузерное расширение для автоматизации работы сотрудников ПВЗ Ozon.

Расширение интегрируется с сайтом `turbo-pvz.ozon.ru` и взаимодействует с локальным backend-сервисом PrintNum для печати номеров ячеек, а также автоматизирует ряд рутинных операций через QR-коды и дополнительные инструменты интерфейса.

# Быстрый старт

1. Убедитесь, что приложение PrintNum запущено.

2. Откройте страницу расширений браузера:

```text
chrome://extensions/
```

3. Включите **Режим разработчика**.

4. Найдите папку, в которой находится основной `.exe` файл программы, и скопируйте путь к этой папке.
   (см. [Как открыть расположение исполняемого EXE файла программы в Windows](https://remontka.pro/open-exe-file-location-windows)).

5. В этой директории находится папка:

```text
extension
```

Именно её необходимо использовать для установки расширения.

Пример структуры:

```text
PrintNum/
├── PrintNum.exe
├── backend/
├── extension/
└── ...
```

6. На странице расширения нажмите:

```text
Загрузить распакованное расширение
```

7. Выберите папку:

```text
extension
```

8. Дождитесь завершения установки.

9. Перезагрузите открытые страницы Ozon.

10. Расширение готово к работе.

> Если расширение уже было установлено ранее, после обновления файлов рекомендуется нажать кнопку «Обновить» на странице расширений или переустановить расширение.

# Возможности

## 📦 Автоматизация работы

- Автоматическая отправка номеров ячеек на печать.
- Автоматизация операций через QR-коды.
- Поддержка выдачи заказов.
- Поддержка оплаты заказов.
- Поддержка возвратов.
- Автоматизация упаковки возвратов.

## 🎨 Настройка интерфейса

- Скрытие бокового меню.
- Скрытие уведомлений.
- Скрытие возвратов.
- Скрытие рекламных баннеров.

## 🖨️ Интеграция с PrintNum

- Отправка номеров на печать.
- Проверка состояния принтера.
- Проверка доступности backend-сервиса.

# Требования

- Chromium-браузер:
  - Google Chrome
  - Yandex Browser
  - Microsoft Edge
  - Opera

- Firefox (экспериментальная поддержка)

Для разработки:

- Node.js 18+
- npm или pnpm

Для работы расширения:

- Запущенное приложение PrintNum
- Запущенный локальный backend:


# Использование

## QR-команды

> ℹ️ Перед использованием QR-кодов их можно распечатать для удобства работы.  
> Файл с QR-кодами можно найти через иконку расширения.

### Выдать заказ (без пакета / M / L)

Раздел:

```text
Выдача заказов → Открытая карточка заказа
```

Для предоплаченных заказов выполняет:

1. Продолжить
2. Выбор пакета
3. Выдать
4. На главную

---

### Выдать всё (без пакета / M / L)

Раздел:

```text
Выдача заказов
```

Для каждого готового заказа выполняет:

1. К выдаче
2. Продолжить
3. Выбор пакета
4. Выдать
5. На главную

---

### Оплатить заказ (без пакета / M / L)

Раздел:

```text
Выдача заказов → Открытая карточка заказа
```

Для неоплаченных заказов выполняет:

1. Продолжить
2. Выбор пакета
3. Провести оплату
4. На главную

Если оплата не прошла и появилась кнопка:

```text
Попробовать ещё
```

повторное сканирование QR-кода продолжит выполнение сценария.

---

### Отказ от товара

Раздел:

```text
Выдача заказов → Открытая карточка заказа
```

Порядок действий:

1. Отсканируйте товар.
2. В течение 3 секунд отсканируйте QR-код причины возврата.

---

### С рекомендацией

Раздел:

```text
Приёмка
```

Автоматически включает переключатель:

```text
С рекомендацией
```

## Автоскрипты

### Упаковка не требуется

Раздел:

```text
Отправка → Отправка перевозок → Прямой/Возвратный поток
```

Алгоритм работы:

1. Выберите возврат для упаковки.
2. Отсканируйте товар.
3. Автоматически будет выбрано:
   - «Упаковка не требуется».
4. Отсканируйте новый штрихкод.
5. Кнопка «Завершить» нажмётся автоматически.
6. Повторно отсканируйте товар с новым штрихкодом.
7. Товар будет добавлен в перевозку.

## Настройки видимости

### Меню

Работает на всех страницах.

Позволяет скрыть элементы бокового меню.

### Уведомления

Работает на всех страницах.

Скрывает всплывающие уведомления в правом верхнем углу.

### Возвраты

Раздел:

```text
Отправка → Отправка перевозок → Прямой/Возвратный поток
```

Позволяет скрыть определенные возвраты.

### Баннер (Выдача возвратов)

Раздел:

```text
Выдача заказов
```

Скрывает рекламный баннер.

> Автоматизация работает только на поддерживаемых страницах Ozon.

# API взаимодействия

Базовый URL:

```text
http://127.0.0.1:5000
```

| Метод | Endpoint        | Назначение           |
| ----- | --------------- | -------------------- |
| GET   | /               | Проверка доступности |
| GET   | /status-printer | Состояние принтера   |
| POST  | /print-number   | Печать номера        |

Пример:

```javascript
await fetch("http://127.0.0.1:5000/print-number", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    number: "12345",
  }),
});
```

